# AI_LOGS.md

## AI Assistance Log

This file documents the use of AI assistance during the development of the Pharmacy Stock Management System.

### Project Overview
The project is a full-stack pharmacy inventory management application designed to manage medicines, batches, stock, dispensing, authentication, and expiry-related alerts.

### AI-Assisted Development Areas

1. **Project Planning**
   - Used AI assistance to understand and structure the requirements of the pharmacy stock management system.
   - Discussed the overall architecture, modules, and development workflow.

2. **Backend Development**
   - AI assistance was used for guidance on Node.js and Express project structure.
   - Received help understanding API routes, middleware, authentication, and server-side logic.

3. **Database**
   - Used AI assistance to reason about SQLite database structure and relationships between users, medicines, batches, and transactions.
   - Received guidance on database initialization and seed data.

4. **Authentication**
   - Used AI assistance to understand JWT-based authentication and password hashing with bcrypt.
   - Received guidance on protecting API endpoints and handling authentication tokens.

5. **FEFO Stock Management**
   - AI assistance was used to understand and implement the First-Expiry-First-Out (FEFO) approach.
   - The logic prioritizes batches with earlier expiry dates when dispensing stock.

6. **Frontend**
   - Used AI assistance for guidance on HTML, CSS, and JavaScript organization and interaction with backend APIs.
   - Received help understanding login, registration, dashboard, medicine, batch, dispensing, and alert workflows.

7. **Debugging and Testing**
   - AI assistance was used to identify possible causes of development errors and to suggest debugging steps.
   - Guidance was also used for running the application, installing dependencies, seeding the database, and testing endpoints.

8. **Documentation**
   - AI assistance helped organize project documentation and explain the technologies, architecture, and development workflow in a clear format.

### Technologies Discussed
- Node.js
- Express.js
- SQLite
- JavaScript
- HTML
- CSS
- JWT
- bcrypt
- REST APIs

### Important Note
AI assistance was used as a development aid for planning, explanation, debugging, documentation, and implementation guidance. The project code should be reviewed and tested by the project developer before deployment or production use.
